# Assignment 10 Project Overview

This folder contains three independent Django applications built with best practices, responsive Bootstrap frontends, and SQLite databases.

## Projects

- `url_shortener`
  - Shortens URLs, tracks clicks, redirects users, and displays a custom result page.

- `todo_app`
  - Task management app with add, edit, delete, complete/incomplete toggles, filtering, and search capabilities.

- `english_dictionary`
  - Dictionary lookup app using dictionaryapi.dev with word definitions, parts of speech, examples, synonyms, antonyms, and recent searches.

## Common Features

- Django models, views, templates, URL routing
- Responsive Bootstrap 5 UI
- Django admin support
- Custom README and `.env.example`
- Static and media file configuration
- SQLite default database
